🐍 1. Install Python dependencies

  1. Make sure Python 3.11+ is installed
  2. Open terminal in the agent/ folder
  3. Run: pip install -r requirements.txt

⚙️ 2. Create your config

  1. Fill in the Configure tab above
  2. Click Download config.json
  3. Move the file to the agent/ folder

📧 3. Gmail App Password

  1. Go to myaccount.google.com
  2. Security → 2-Step Verification → App passwords
  3. Create one for "Mail" and paste it in Configure tab

🤖 4. Get Anthropic API key (free)

  1. Sign up at console.anthropic.com
  2. Create an API key
  3. Paste it in the Configure tab
  4. Without key: agent uses a built-in email template

🚀 5. Run the agent

  • Test run (no emails sent): python agent.py --dry-run
  • Real run: python agent.py
  • Custom config: python agent.py --config myconfig.json
  • View log: cat agent.log
  • View results: open results.csv in Excel / Google Sheets
Always test with --dry-run first! Check results.csv to confirm the agent is finding the right brands before enabling real sends.
